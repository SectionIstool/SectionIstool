## 功能
### 主要功能
- [ ] SectionIstool 插件式程序对应需求下载
- [ ] 支持全部的 <班级一体机的优质软件> 的下载、更新(更新功能根据实际情况而定)
- [ ] 支持导出、导入配置文件(一键下载对应软件)
- [ ] 支持自动更新(根据实际情况而定)
- [ ] 支持软件的卸载

### 设置功能
- [ ] 设置界面支持设置、修改软件的大部分功能
